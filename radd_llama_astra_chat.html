Start here · How to make Radd work
  1. Download this HTML file and open it in Chrome or Edge.
  2. Create your own API key at Groq Console → API Keys.
  3. Click the Llama status button below or الإعدادات (Settings). Choose Groq and paste your key. It stays in memory for this page session; re-enter it after refreshing.
  4. Keep API URL https://api.groq.com/openai/v1 and text model llama-3.3-70b-versatile. If Llama is unavailable for your account, use qwen/qwen3.8-27b for the text model. Click جرّب الاتصال (Test connection). Wait for the green success message.
  5. Return using محادثة جديدة. Paste a conversation with “Me:” and “Them:” labels, or upload a readable screenshot. Fill in the last incoming message if the speakers are unclear.
  6. Choose your goal, relationship, length and language. Add a sample of your own writing if you want. Press the pink arrow.
  7. Switch tones, copy a reply, or use تعديل to rewrite it. Your original context stays attached to rewrites.

Screenshots: require a vision model. The default image model is qwen/qwen3.8-27b (Qwen, not Llama). If unavailable for your account, choose a currently supported vision model from your provider, or remove the image and paste its text.

Connection problem? 401/403: check your key and model access. 404: check model name. 429: read the provider explanation shown in the app. Requests are capped at 800 output tokens and generate two replies per tone. If your remaining per-minute budget is lower, wait for it to reset. A request-too-large error requires lowering the output budget further, not repeated retries. Network/CORS: try serving this file locally with Python: open a terminal in its folder, run python -m http.server 8000 --bind 127.0.0.1 (Windows: py -m http.server 8000 --bind 127.0.0.1), then open http://localhost:8000/radd_llama.html. If the provider still blocks browser requests, a backend proxy is required.

Your text and images go to the selected AI provider when you generate. This is a personal browser app; public deployment needs a backend to protect API credentials. Conversation history lasts only until this page closes or refreshes.

Reference: Groq quickstart · Vision documentation
